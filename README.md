# Nakul Jangra — Professional Website

GitHub Pages site for Nakul Jangra, positioned around B2B marketing strategy for legal services, Alternative Legal Service Providers (ALSPs), Legal Process Outsourcing (LPO), LegalTech and eDiscovery.

## Files

- `index.html` — site content, SEO metadata and structured data
- `styles.css` — visual system and responsive layout
- `script.js` — navigation scroll-spy and hero counters
- `robots.txt` — crawler access and sitemap declaration
- `sitemap.xml` — XML sitemap

## Deployment

The site is designed for GitHub Pages. Keep the repository public and configure Pages to deploy from the branch/folder containing these files.
