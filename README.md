# Nakul — portfolio site

A static site (plain HTML/CSS/JS, no build step). Deploys free on GitHub Pages.

## Deploy it

1. Create a new GitHub repo named `<your-username>.github.io` (this exact name gives you the URL `https://<your-username>.github.io`; any other repo name works too, but the URL becomes `https://<your-username>.github.io/<repo-name>`).
2. Push these three files (`index.html`, `styles.css`, `script.js`) to the repo's default branch.
3. In the repo: **Settings → Pages → Source → Deploy from a branch → main / (root)**. Save.
4. Wait 1–2 minutes, then visit the URL from step 1.
